## About the Toolkit
Welcome to the Easy Digital Twins Toolkit. This toolkit makes it easy to bring a Digital Twin (of Rotterdam) into your Unity projects and interact with it.

The Toolkit has the following features which make it easier to start developing an XR application with live City data:
- A User Manual with setup, usage and deployment guide.
- Integration of Data Catalogues for browsing selecting and importing Datasets and Digital Twins.
- Automatic Installation of Dependencies and Cesium for Unity for rendering 3D meshes from the City Data.
- Automatic Scene, Georeference and Cesium for Unity configuration.
- Plug-and-play custom made light weight controllers prefabs with gamepad support.
- Example scenarios and scripts to get you started.
- Optimalisation and configuration tools for performance and deployment.
